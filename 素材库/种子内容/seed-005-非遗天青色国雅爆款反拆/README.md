# 种子内容素材包：非遗天青色国雅爆款反拆

## 用途

这个文件夹用于收集“非遗 / 汝窑 / 雨过天青 / 红旗金葵花国雅”这条种子内容的可替换素材。

后续 AI 裂变时，会优先根据 `节奏段 + 细节包` 去匹配素材，而不是只按图片或视频文件名判断。

本版素材包已经做过简化：不是把素材合并成抽象概念，而是删除重复近似的画面分类，保留“画面里到底拍到了什么”的具体素材桶。

自动裂变流程见：

`outputs/seed-005-非遗天青色国雅爆款反拆/AI裂变执行工作流.md`

## 素材放置说明

素材包只放实拍素材或真实可用的视频/图片素材。字幕、标题、贴纸、转场、黑底尾板、关注引导画面属于 Remotion/AI 后期层，不进入素材包。

### 节奏段1_汝瓷质感

用于开场和“雨过天青”审美铺垫，先给观众质感，不急着解释。

- `汝瓷器物近景/`：碗、瓶、盘等汝瓷或相似瓷器的近景，能看清器物形态。
- `汝瓷釉面纹理/`：天青釉、瓷面光泽、开片纹、冰裂纹、碗口或瓶身局部。原来的“釉面微距 / 冰裂纹 / 天青釉色微距”统一放这里。
- `雨后天空水面/`：雨停、云散、青色天空、水面涟漪等真实自然画面，用来承接“雨过天青”。

### 节奏段2_文化铺垫

用于讲“九百年前、宋徽宗做梦、汝窑烧色”的文化故事。本 demo 暂时不单独做黑底悬念标题，开头文字如果后续需要，直接由 Remotion 的纯文字字幕或 overlay 实现。

- `汝瓷陈列环境/`：瓷器放在展柜、桌面、展厅、暗背景或陈设环境里的镜头。
- `古画文物纹样/`：宋画、古典纹样、文物细节、书页、展陈图文等明确能被看到的文化画面。没有这类素材可以先空着，不强求。

### 节奏段3_国雅露出

用于从文化审美过渡到红旗金葵花国雅，让产品承接“天青色 / 东方审美”的价值。

- `国雅整车外观/`：完整车身、侧面、前 45 度、车尾、车身行进或展车全貌。
- `国雅车漆近景/`：车漆光泽、车身局部、天青色或相近色的漆面细节。
- `国雅前脸格栅/`：前脸、竖向格栅、车头气场。只放格栅明显的画面。
- `国雅车标立标/`：升降式立标、金葵花标识、车尾铭牌、车型字标。只放标识明显的画面。

### 节奏段4_提问结尾

用于评论提问和自然收束，画面仍以实拍产品或氛围素材为主。

- `国雅停留定格/`：镜头停在整车、车头、车尾、立标或车漆上的稳定画面，适合压“你觉得怎么样？”这类提问字幕。关注尾板和黑底收束由 Remotion 生成，不放素材包。

### 通用补充

可用于任何节奏段的补充氛围素材。

- `可放字幕空镜/`：画面主体不抢、留白比较多、适合压字幕的实拍空镜。
- `同色光影过渡/`：天青、瓷白、黑灰、红色点缀等同色系光影实拍画面，用于两段之间自然过渡。纯特效转场不放这里。

## 放素材建议

1. 能明确支撑文案的素材，放进对应细节包。
2. 不确定放哪的素材，先放进 `通用补充/`。
3. 如果一个素材能支撑多个段落，优先放到最强绑定的段落。
4. 汝瓷、国雅车身、格栅、立标属于强绑定素材，尽量不要只放通用补充。
5. 同一个镜头不要为了多个关键词重复放入多个文件夹；素材描述库里写清楚可支持的画面语义即可。
