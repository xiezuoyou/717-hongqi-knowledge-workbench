# 813盛典现场，红旗智能科技的‘小心机’都藏在这了

**内容方向**：智能科技体验
**切入角度**：用第一视角体验，带用户感受那些‘用起来才懂’的智能细节
**状态**：规划中

## 逻辑线

### 1. 开场钩子：一个被自动解决的‘小麻烦’（5s）

**目的**：用具体、微小的场景瞬间抓住注意力，引发好奇，点明‘智能体验’主题。

**要拍的画面**：
- 观众手持饮料，车门自动感应开启
- 雨天，观众靠近车辆时雨刮自动启动
- 观众走近车辆，氛围灯自动点亮迎接

**画面要求**：
- 第一人称视角拍摄
- 突出‘无需动手’的自动化瞬间
- 画面干净，主体明确

**建议素材数量**：1-2 个视频，裂变时随机选 1 个

### 2. 核心体验点1：能‘听懂’你、‘看懂’你的交互（8s）

**目的**：展示智能座舱的感知与反馈能力，让用户觉得它‘聪明’且‘贴心’。

**要拍的画面**：
- 语音助手精准响应复杂指令（如‘我有点热，把空调调低两度，顺便打开座椅通风’）
- 手势控制切换歌曲或调节音量
- 眼神视线唤醒功能（如看向中控屏时屏幕自动点亮）

**画面要求**：
- 拍摄清晰的操作过程和即时反馈
- 展示从发出指令到执行完毕的完整流程
- 突出‘懂你’的轻松感

**建议素材数量**：3-4 个视频，裂变时随机选 1 个

### 3. 核心体验点2：让旅程更省心的‘隐形帮手’（7s）

**目的**：呈现技术如何在具体场景中解决实际痛点，强调实用性和体验提升。

**要拍的画面**：
- 智能驾驶辅助在模拟场景中平稳跟车、车道保持（安全环境演示）
- AR-HUD导航将路线信息投射在前风挡，视线无需离开路面
- 系统主动识别疲劳状态并发出提醒

**画面要求**：
- 通过第一视角或乘客视角呈现
- 强调‘轻松’、‘安心’的体验感受
- 避免复杂技术操作界面特写

**建议素材数量**：3-4 个视频，裂变时随机选 1 个

### 4. 高潮与共创：粉丝在现场‘玩’智能（6s）

**目的**：链接活动背景（粉丝盛典），展示真实用户与科技的互动，增强真实感和社群归属感。

**要拍的画面**：
- 粉丝在互动区体验并讨论某个有趣的智能功能
- 车友互相演示如何使用智能场景模式（如露营模式）
- 粉丝用智能科技完成一个小挑战或趣味互动

**画面要求**：
- 拍摄自然、生动的互动瞬间
- 收录真实的惊叹或讨论声
- 突出‘一起玩科技’的欢乐氛围

**建议素材数量**：3-4 个视频，裂变时随机选 1 个

### 5. 结尾钩子：一句‘用了就回不去’的感叹（4s）

**目的**：强化体验后的感受，引发观众共鸣和向往，引导对线下活动的期待。

**要拍的画面**：
- 观众体验后下意识地感叹（如‘这个太方便了’）
- 一个功能带来舒适感的特写（如缓缓放倒的座椅配合舒缓音乐）
- 车辆与盛典环境融合的美观镜头

**画面要求**：
- 以体验者的自然反应或满足表情收尾
- 画面氛围轻松、愉悦
- 可以带有品牌标识但不刻意

**建议素材数量**：1-2 个视频，裂变时随机选 1 个

## 拍摄说明

1. 按照上述逻辑线顺序拍摄
2. 每段拍摄多个角度/时刻的视频，放到对应文件夹

4. 拍摄完成后，在对应文件夹下创建 `素材说明.md`，描述每个视频的画面内容
