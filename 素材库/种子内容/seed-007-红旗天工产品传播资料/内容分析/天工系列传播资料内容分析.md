# 天工系列传播资料内容分析

## 资料范围

本分析基于以下三份原始传播手册提取：

- `红旗天工05产品传播手册完整版-5-22.docx`
- `红旗天工06产品传播手册-4.21（智驾调整版）.docx`
- `红旗新能源E202（天工08）标准化传播手册（5.0锁定版）-1110.docx`

## 总体定位

天工系列资料的核心不是单纯讲参数，而是把红旗新能源产品包装成一套完整的“智能新能源豪华体验”：

- 技术底座：天工平台 + 九章平台
- 智能驾驶：红旗司南智驾
- 智能座舱：红旗灵犀座舱
- 品质安全：红旗品质、珠穆朗玛计划、安全车身、电池安全
- 续航驾控：900V / 高压补能 / 高效电驱 / 低温低衰减 / 底盘调校
- 设计美学：新智国潮、东方审美、红旗设计传承
- 豪华体验：座椅、静谧、空间、天幕、音响、健康材质
- 竞品攻防：特斯拉、小鹏、比亚迪、极氪等同级产品对比

## 车型拆解

### 红旗天工05

基础定位：

- 新智国潮豪华纯电轿车
- 九章平台与天工平台首款纯电轿车
- 面向年轻、科技、城市出行和纯电轿车用户

关键参数与卖点：

- 车身尺寸：4820mm x 1915mm x 1480mm
- 轴距：2900mm
- 电池容量：62kWh / 85kWh / 98kWh
- CLTC 续航：550km / 750km / 850km
- 电压平台：400V / 900V
- 900V 版本 10%-80% SOC 充电时间约 12min
- 百公里电耗：约 12.1kWh
- 风阻系数：0.213Cd
- 底盘：前双叉臂 + 后五连杆
- 竞品参考：特斯拉 Model 3、小鹏 P7+、比亚迪海豹 EV、极氪 007

传播重点：

- 轿车姿态、溜背造型、低风阻与长续航
- 司南智驾的城市领航、高速领航、全场景泊车
- 灵犀座舱与 DeepSeek 融合、65寸双焦面 AR-HUD、智能语音
- 用“新智国潮豪华纯电轿车”承接红旗新能源的年轻化表达

适合生成的内容：

- “天工05为什么适合年轻人”
- “纯电轿车怎么讲智能和豪华”
- “天工05和 Model 3 / 小鹏 P7+ 怎么对比”
- “用一条短视频讲清楚天工05的长续航和智能座舱”

### 红旗天工06

基础定位：

- 新智国潮豪华纯电 SUV
- 天工平台纯电 SUV 产品
- 面向家庭、城市 SUV、新能源升级用户

关键参数与卖点：

- 车身尺寸：4750mm x 1900mm x 1640mm
- 轴距：2900mm
- 电池容量：62kWh / 85kWh / 98kWh
- CLTC 续航：520km / 660-700km / 730-780km
- 电压平台：400V / 900V
- 900V 高压补能，10%-80% SOC 充电时间约 12min
- 百公里加速：部分四驱版本可到 3.9s
- 百公里电耗：约 12.9kWh
- 风阻系数：0.259Cd
- 空间利用率、后备箱、座椅舒适和全时智能四驱是 SUV 表达重点
- 竞品参考：特斯拉 Model Y、极氪 7X、比亚迪海狮 07 EV、小鹏 G6

传播重点：

- SUV 家庭出行、舒适空间、长途续航和补能效率
- 红旗司南智驾：无图城市领航、高速领航、跨楼层记忆泊车
- 红旗灵犀座舱：DeepSeek、大模型语音、65英寸 AR-HUD、场景模式
- 豪华 SUV 底蕴：全软包、静谧空间、全景天幕、隐私玻璃、座椅舒适

适合生成的内容：

- “天工06适合家庭用户的几个理由”
- “天工06怎么对比 Model Y”
- “一条视频讲天工06的空间、续航和智能驾驶”
- “用不堆参数的方式讲天工06的豪华 SUV 感”

### 红旗天工08 / E202

基础定位：

- 红旗智造豪华纯电 SUV
- 天工平台与九章平台首创/代表性产品
- 对应资料中以 E202 命名，可作为天工08相关传播资料使用

关键参数与卖点：

- 车身规格：4925mm x 1950mm x 1680mm
- 轴距：3000mm
- CLTC 续航：最高约 730km
- 最大电池容量：111kWh
- 常温 10%-80% SOC 充电最快约 20min
- 低温 -10 摄氏度 10%-80% SOC 充电最短约 38min
- 百公里加速：部分版本 3.9s
- 电驱系统最高效率：96%
- 支持 L2.9 高阶智能辅助驾驶
- 智能泊车、城市 NOA、高速领航、跨层记忆泊车是核心智能化内容

传播重点：

- 红旗汽车“洞见 SIGHT”战略：安全、智能、绿色、健康、美妙
- 天工平台首创之作，强调平台能力、技术底座、红旗 All In 新能源
- 豪华纯电 SUV 的平台价值：安全、电驱效率、低温能力、补能体验、舒适底盘
- 东方设计美学：故宫中轴线、敦煌、旗贯长红标识、旌旗侧标灯、劲锋之瞳前灯

适合生成的内容：

- “天工08 / E202 的平台技术怎么讲”
- “红旗新能源为什么强调 SIGHT 战略”
- “把天工08讲成一条旗舰纯电 SUV 种草视频”
- “从安全、智能、绿色、健康、美妙五个维度拆解天工08”

## 共通卖点体系

### 1. 司南智驾

关键词：

- 全国放心开
- 越开越好开
- 惯导三目视觉系统
- 无图城市领航
- 高速领航辅助
- 全场景泊车
- 跨楼层记忆泊车
- 端到端 / 类人组合驾驶辅助

内容表达方向：

- 不建议只堆“智驾参数”，更适合讲“城市、高速、停车这三个高频场景都能帮忙”。
- 对 C 端用户，重点放在“减轻驾驶压力”“停车更从容”“长途更轻松”。
- 对审核口径，涉及自动驾驶时应统一使用“辅助驾驶 / 组合驾驶辅助”，避免夸张成完全自动驾驶。

### 2. 灵犀座舱

关键词：

- 越用越懂你
- DeepSeek 融合
- 大模型 AI 语音
- 四音区语音识别
- 65寸 / 65英寸双焦面 AR-HUD
- 场景模式
- 数字钥匙
- 全平台手机互联
- 丹拿音响 / 自研音响
- 自进化 AI 智能空调

内容表达方向：

- 核心是“车不只是工具，而是更懂人的移动空间”。
- 适合做体验类短视频：语音控制、AR-HUD、场景模式、K歌/观影/游戏等娱乐功能。
- 适合做“年轻人第一次坐进天工系列会注意到什么”的种草表达。

### 3. 红旗品质与安全

关键词：

- 红旗品质
- 磐石安全
- 珠穆朗玛计划
- C-NCAP / E-NCAP 双五星
- 9H4M 笼式车身
- 电池安全
- IPX8 / IPX9
- 主动安全 / 被动安全
- 母婴级健康材质
- 0甲醛 / 0异味
- 信息安全 / 电磁安全

内容表达方向：

- 安全是天工系列非常强的底层心智，适合和家庭、长途、新能源电池焦虑绑定。
- 可以用“看不见的地方更舍得下功夫”来组织内容。
- 涉及测试、标准和具体数值时，发布前需要对照正式版本复核。

### 4. 续航补能与驾控

关键词：

- 900V 高压平台
- 10%-80% SOC
- 充电 10 分钟补能 500 公里
- 低温续航
- 智能热管理
- 高效电驱
- SiC 逆变
- 低风阻
- 前双叉臂 + 后五连杆
- 智能四驱
- 对外放电 / V2V / V2G

内容表达方向：

- 适合解决用户的“新能源三焦虑”：续航焦虑、补能焦虑、低温焦虑。
- 天工05偏“低风阻、长续航、城市纯电轿车效率”。
- 天工06偏“家庭 SUV 长途、空间、四驱与补能”。
- 天工08偏“平台技术、旗舰纯电 SUV、全场景能力”。

### 5. 东方设计美学

关键词：

- 新智国潮
- 智慧美学
- 尚·致·意
- 故宫中轴线
- 双轴线设计
- 旗贯长红
- 旌旗侧标灯
- 劲锋之瞳前灯
- 旗扬鹰飞尾灯
- 中和比例
- 天工色彩

内容表达方向：

- 设计表达最好不要写成“很漂亮”，而是用“红旗设计传承 + 新能源动感进阶”来讲。
- 天工05适合讲运动溜背、超低风阻、年轻科技。
- 天工06适合讲豪华 SUV 姿态、东方比例和灯组寓意。
- 天工08适合讲平台旗舰、故宫/敦煌等文化灵感。

## AI 检索建议

用户可能这样问：

- “帮我找天工05的核心卖点”
- “天工06和 Model Y 怎么讲对比”
- “天工08的 SIGHT 战略是什么”
- “帮我写一条天工05的短视频口播”
- “红旗天工系列有哪些共同技术标签”
- “帮我审核这段天工06文案有没有夸大”
- “天工系列怎么讲智能座舱，不要太参数化”

系统应优先检索：

1. 用户提到具体车型时，先锁定车型。
2. 用户提到智驾、座舱、安全、续航、设计、竞品时，按主题检索对应章节。
3. 用户提到“发布”“审核”“能不能这么说”时，优先返回谨慎口径和需要复核的参数。
4. 用户只说“天工”时，可先返回三车型差异，再追问或给出可选方向。

## 内容裂变方向

### 短视频方向

1. “一句话讲清天工05/06/08”
2. “不是参数堆料，而是解决真实用车焦虑”
3. “从停车、高速、城市路况讲司南智驾”
4. “从家人乘坐体验讲天工06”
5. “从 SIGHT 战略讲红旗天工08”

### 图文方向

1. 车型卖点九宫格
2. 竞品对比清单
3. 用户高频问题 Q&A
4. 智驾/座舱/安全/续航分主题卡片
5. 天工系列车型矩阵介绍

### 审核方向

需要谨慎的表达：

- 不要把辅助驾驶说成自动驾驶。
- 不要把“预期”“后续 OTA”“计划时间”写成已经交付。
- 不要直接使用攻击性竞品话术。
- 涉及 CLTC、充电时间、电池容量、百公里加速、风阻、达成率等参数，发布前需要对照正式配置表。
