# 种子内容资料包：红旗天工产品传播资料

## 用途

这个文件夹用于收集 `红旗天工系列` 的产品传播手册、标准化表达、参数卖点和竞品攻防资料。

这条种子不是活动现场素材，也不是单张图片素材，而是：

```text
产品传播手册 + 车型资料拆解 + AI 检索底稿 + 内容裂变依据
```

后续 AI 裂变时，可以从这里提取车型信息、传播主题、配置卖点、竞品对比和审核口径，用于生成：

- 车型介绍口播
- 产品亮点短视频脚本
- 直播讲解提纲
- 小红书/抖音标题方向
- 竞品对比问答
- 内容发布前事实审核

## 当前分析结论

三份资料的共通传播骨架非常清晰：

```text
新智国潮 / 天工平台 / 九章平台
→ 司南智驾
→ 灵犀座舱
→ 红旗品质与安全
→ 续航补能与驾控
→ 东方设计美学
→ 豪华舒适体验
→ 竞品攻防
```

车型区分建议：

- `天工05`：更适合讲“新智国潮豪华纯电轿车”“年轻科技感”“超低风阻与长续航”。
- `天工06`：更适合讲“新智国潮豪华纯电 SUV”“家庭舒适”“SUV 空间与智能四驱”。
- `天工08 / E202`：更适合讲“天工平台首创之作”“洞见 SIGHT 战略”“旗舰纯电 SUV”“平台技术底座”。

## 使用边界

1. 这些资料适合作为 AI 检索、脚本生成和事实审核的依据。
2. 参数、时间节点、版本称谓涉及正式发布口径时，后续对外发布前仍建议人工复核。
3. 竞品攻防内容适合内部创作参考，不建议原样照搬成公开攻击性表达。
4. 如果用户只是搜索图片素材，不应直接返回这些 docx；如果用户搜索车型资料、卖点、参数、话术，则优先读取这里的结构化分析。
