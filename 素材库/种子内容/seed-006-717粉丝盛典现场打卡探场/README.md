# 种子内容素材包：717 粉丝盛典现场打卡探场

## 用途

这个文件夹用于收集 `717 粉丝盛典` 现场探场、打卡路线、活动氛围类素材。

这条种子不同于 `非遗天青色国雅` 的高级文化短片，它更偏：

```text
活动现场实拍混剪 + 字幕/旁白承接 + 后期包装 + 快速种草
```

后续 AI 裂变时，会根据 `节奏段 + 细节包` 匹配素材。

素材包边界：

```text
素材包只放实拍素材。
字幕、贴纸、转场、尾板、关注引导画面属于后期 AI / Remotion 制作，不进入素材包。
```

重要约束：

```text
裂变成片不出现真人主持或出镜口播。
原片中的真人只作为参考，不作为后续裂变必须复用的视觉主体。
```

## 素材放置说明

### 节奏段1_入口开场

用于开头快速进入 717 盛典语境。

- `红旗盛典拱门/`：红色入口拱门、红旗盛典主视觉、红毯入口。
- `红毯人流/`：现场观众、工作人员、入场动线。

### 节奏段2_位置指引

用于说明活动地点和打卡路线。

- `红旗国际汽车公园定位/`：地标、入口环境、能说明地点的实拍画面。
- `欢迎回家指示牌/`：欢迎回家、这很红旗、活动路线牌。
- `活动地图与路标/`：区域指示牌、路线图、分区指引。

### 节奏段3_节目打卡

用于展示现场“有东西可玩、可看、可拍”。

- `精彩演出区域/`：演出、舞台、节目提示、表演区。
- `互动打卡动作/`：观众互动、打卡动作、现场互动装置，不以真人主持为核心。
- `现场活动物料/`：活动现场实拍物料、展板、区域装置、打卡背景。

### 节奏段4_休闲体验

用于展示更松弛的现场体验。

- `露营休闲区/`：露营区、草坪、户外休息区。
- `草坪帐篷/`：帐篷、天幕、休闲座椅。
- `轻松玩乐氛围/`：跳跃、互动、轻松走动、亲子或朋友氛围。

### 节奏段5_赛车展示

用于承接具体亮点，让视频从“活动氛围”进入“可看的车”。

- `超哇赛车展车/`：超哇赛车、蓝色展车、车前打卡。
- `车身外观/`：车身侧面、前脸、局部线条。
- `赛道围栏与打卡位/`：红白赛道格、围栏、展区边界。

### 节奏段6_关注收尾

用于账号导流前的实拍收束画面。真正的关注文字、尾板、账号页由后期生成。

- `红旗粉丝墙/`：粉丝墙、红旗主题背景板、车模背景板。

### 通用补充

可用于补节奏。转场、贴纸和字幕不放在素材包内。

- `人群空镜/`：现场人流、观众走动、排队。
- `红色品牌视觉/`：红旗红、品牌物料、活动主视觉。

## 放素材建议

1. 这个种子默认目标比例是 `9:16`，请优先放竖屏素材。
2. 不需要找真人主持或出镜口播素材，优先找活动现场、指示牌、展区和氛围画面。
3. 贴纸、字幕、尾板、关注页不需要找素材，后续由 Remotion 或 AI 包装生成。
4. 如果素材只能说明活动氛围，不能说明具体区域，请放入 `通用补充/人群空镜` 或 `通用补充/红色品牌视觉`。
5. 如果文案提到具体地点、区域或活动项目，必须有对应细节包素材支撑。
