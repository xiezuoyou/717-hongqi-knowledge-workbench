# 717 红旗传播工作台原型

React + Vite 实现的产品雏形，用来验证 717 传播工作台的三类核心诉求：

- 一键成片：从种子内容包生成发布视频、字幕、文案和素材清单
- 盛典话题脚本：从热点内容包生成标题、脚本、分镜和素材建议
- 脚本审核：基于官方资料库核查事实、风险和表达

## 本地运行

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```

## 主要文件

- `src/main.jsx`：页面结构、模拟数据和交互逻辑
- `src/styles.css`：工作台样式和响应式布局
- `717传播工作台产品设计.md`：产品逻辑与后续迭代依据
