# 717 红旗传播工作台原型

这是一个面向 813/717 专题传播场景的知识库与 AI 工作台原型，用来验证资料沉淀、内容生产、素材收集、审核和种子内容加工的整体流程。

## 项目说明

- 首页先登录，再进入工作台
- 左侧工作台切换专题种子库、知识库、AI 智库和个人中心
- 知识库支持产品资料、传播文件、素材资源和种子内容
- AI 智库支持资料搜索、内容制作、内容审核和追问式输出
- 文件收集空间支持素材归集、重命名、删除和批量下载

## 本地运行

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```

## 主要文件

- `src/main.tsx`：页面结构、状态流转和主要交互逻辑
- `src/styles.css`：工作台视觉样式和响应式布局
- `素材库/`：专题资料、种子内容和素材组织结构
